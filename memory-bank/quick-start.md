# Quick start — Eupry Design System

1. Read the root AGENTS.md or CLAUDE.md, WORKFLOW.md, toc.md, and activeContext.md.
2. Read the latest monthly task summary and the source references in projectbrief.md.
3. Inspect current git status and the files relevant to the task.
4. Verify changes using: Validate tokens.json as JSON and check that DESIGN.md, the quick agent reference, and packaged skill agree after changes..
5. Complete the final task document and update activeContext.md in the same change.

Deployment reference: Follow README.md and skill/INSTALL.md for consumer setup; no Railway service is attached.
